# Conservative source reconstruction, 2026-10-14

The public `decompile(&ScriptUnit)` API remains available. `decompile_with_context`
accepts a `MethodContext` derived from the same unit; stale or forged contexts
retain exact P-code. The indexed context includes the raw ABC SHA-256, method and
body indices, unique trait owner, script owner, parameter/return types, optional
defaults, and exact namespace identities. Private and protected pool identities
are never merged by display spelling.

Implemented method families include proven owned lexical receivers, typed
assignment coercion, optional signatures, mutable activation cells and closures,
reducible loop completions, empty-stack switch fallthrough, and one disjoint
typed catch. Local `getscopeobject` indices are independent of inherited scope
depth; `getouterscope` reads the captured chain. Activation defaults are explicit
and type-correct before the first store. Unknown scope objects, activation escape,
ambiguous bindings, unrepresentable type annotations, unaccounted effects, and
unsupported control flow retain exact P-code.

`decompile_document` reconstructs complete bounded class documents only after
proving all class, script bootstrap, method, and initializer effects. Member
owners and visibility, class declaration order, superclass capture order and
multiplicity, and transitive closure bodies are checked. Canonical class documents
accept empty static initializers and a bounded ordered static-var initialization
tier; script traits still must be class-only. The static tier proves exact owned
slot identities, primitive expressions, and direct array allocations/aliases. It
emits assignments in bytecode order inside one class initializer block, with no
temporary variables or auxiliary traits. Values cannot remain live across a
write. Source expression types are checked separately from runtime primitive
proofs: implicit slot coercions or numeric operators that AS3 cannot express
without an unproven conversion retain P-code. Const writes, calls, local stores,
captured scopes, handlers, branches, ambiguous names, and allocation duplication
remain unsupported in this tier.
`decompile_document_with_hierarchy` additionally accepts immutable external type
metadata derived from a SHA-256-verified SWC. Movie types take precedence over SDK
types; missing, cyclic, ambiguous, or mismatched ancestry retains P-code. SDK code
is never executed or copied.

The CLI operations are `method_context`, `decompile_document`, and
`hierarchy_contract SWC SHA256`; the worker also accepts `source_document` as an
alias. Document operations accept
`--hierarchy-swc PATH --hierarchy-sha256 SHA256`; worker requests use
`hierarchy_swc` and `hierarchy_sha256`. Complete exports have
`state=structured` and `source_tier=complete_document`. Partial owned method
fragments have `state=pcode_only`, `source_tier=owned_method_fragments`, no complete
documents, and `requires_original_owner=true`. Fragments must stay in the original
class context. Exact P-code accompanies both tiers.

The integration contract uses playerglobal32 SWC SHA-256
`7d4d6168d27603cfb3b750302448e354e0bbc1bdd58f5d101c3dcf6891e9bb65`.
Its verified library SWF has SHA-256
`40e84dc8bbfc748067fd7c2d244051c99c38e9867565d03ebdee063bcdde65f1`,
622 class records, and zero ambiguous records. These are parsed facts from this
specific SDK, not assumed names or a built-in Sprite ancestry shortcut.

Dedicated tests cover bytecode/source ordering, private namespace separation,
mutable and independent closure cells, early typed-slot reads, invalid scopes,
type shadowing, symbol budgets, loop completions, switch fallthrough, catch scope
reset, bootstrap capture order, and bounded verified SWC extraction. Optional
Flex tests compile original and reconstructed coerce, catch, and complete Sprite
class fixtures. The parent runtime harness confirmed exact bounded full-AVM2
Ruffle traces for coerce (eight lines, including null, undefined, and TypeError
1034) and catch (two lines). This is fixture evidence, not general AVM2 parity.

Pending families retain P-code: general multiple/nested catches and finally;
interface and script-function/slot document exports; static class initializers
outside the ordered static-var tier; activation class/generic slot defaults with unproven class-loading
effects; unknown captured scopes; unsupported namespace aliases and versioned
API type names. The shared Python compiler remains the source compilation path.
No Rust AS3 compiler, general JPEXS parity, or universal runtime fidelity is
claimed. Frozen benchmark binaries and release packages were not overwritten.

All implementation in this change is original GPL-3.0-or-later code. No JPEXS
source was adapted.
